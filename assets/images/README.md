# Image slots

Drop real photos/video stills into this folder using these exact filenames, and they'll automatically fill the placeholder blocks on the site once wired up in `index.html`:

| Filename              | Used for                          | Suggested shape |
|------------------------|------------------------------------|------------------|
| `hero-bg.jpg`           | Hero section background            | Wide / landscape, dramatic gym or fighter shot |
| `gym-interior-1.jpg`    | About section (gym interior)       | Portrait or square |
| `coach-howell-lewis.jpg`| Coach Howell Lewis bio photo       | Portrait |
| `gallery-1.jpg` … `gallery-6.jpg` | Gallery grid (6 slots)   | Square / 4:3 |

Once you send over the b-roll and pictures, I'll drop them in here and swap each `.placeholder-media` block in `index.html` for a real `<img>` tag (or a `background-image` for the hero) — no other changes needed.
